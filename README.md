## Aim: Basics of Python
Theory
Python is a high-level, interpreted programming language widely used in Data Science due to its simplicity and powerful libraries. In the initial phase of Exploratory Data Analysis, it is crucial to understand how Python stores and displays information.

This experiment covers three fundamental concepts:

Variable Assignment: Python is dynamically typed, meaning you do not need to declare a variable's type (like int or string) explicitly. The interpreter determines the type based on the value assigned.

Data Types: * Integer (int): Used for whole numbers (e.g., x = 2).

List: A collection of items which is ordered and changeable. It is defined using square brackets (e.g., y = [1, 2, 5]).

String (str): A sequence of characters used for text (e.g., z = "vedant").

The print() Function and sep Parameter: The print() function outputs data to the console. By default, it separates multiple arguments with a space. However, using the sep (separator) parameter allows you to define a custom string between the values. Using sep="\n" (the newline character) ensures each variable is printed on a new line.
